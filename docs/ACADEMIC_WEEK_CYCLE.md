# Навчальний цикл: чисельник і знаменник

## Правило

Навчальний цикл рахується тільки по реальних навчальних тижнях.

```text
ЧИСЕЛЬНИК
↓
ЗНАМЕННИК
↓
КАНІКУЛИ = ПАУЗА
↓
ЧИСЕЛЬНИК
↓
ЗНАМЕННИК
```

Канікули не є окремим чисельником або знаменником і не збільшують
академічний індекс.

Те саме правило використовується для чергування класів.

## Джерело

Початковий календар — `data/default/calendar.json`; робочий — `data/current/calendar.json`. Локальні зміни з адмінпанелі зберігаються окремо в `data/calendar_override.json`. Навчальний індекс і чергування використовують ці спільні джерела.

## Канікули

```text
Осінні: 26.10.2026–01.11.2026
Зимові: 28.12.2026–10.01.2027
Весняні: 29.03.2027–04.04.2027
```

## NORMAL / SHELTER

Один `schedule.week` визначає файл розкладу:

```text
NORMAL:
  ЧИСЕЛЬНИК -> schedule_numerator.json
  ЗНАМЕННИК -> schedule_denominator.json

AIR_RAID / SHELTER:
  ЧИСЕЛЬНИК -> shelter_numerator.json
  ЗНАМЕННИК -> shelter_denominator.json
```

Отже після канікул і звичайний розклад, і укриття переходять на той самий
правильний наступний тип тижня.

## Чергування

Той самий `academic_week_index` керує ротацією:

```text
10-А → 10-Б → 10-В → 10-Г → 11-А → 11-Б → 11-В → 11-Г
```

Наприклад:

```text
19–25.10.2026  ЗНАМЕННИК • 11-Г
26.10–01.11    ПАУЗА
02–08.11       ЧИСЕЛЬНИК • 10-А
```

та:

```text
22–28.03.2027  ЧИСЕЛЬНИК • 10-В
29.03–04.04    ПАУЗА
05–11.04       ЗНАМЕННИК • 10-Г
```

## Operations

`Operations → ЧЕРГУВАННЯ` показує:

- поточний черговий клас;
- наступний клас;
- тип тижня;
- `ПАУЗА → ЧИСЕЛЬНИК/ЗНАМЕННИК` під час канікул;
- номер навчального тижня.
