# Склад чистого проєкту Orange Pi

Основа — LyceumTV 3.6.1. У цьому репозиторії одна версія 3.7.1 для Orange Pi PC; архіви попередніх Raspberry Pi релізів не додаються.

У ZIP входять сервер, TV/панелі, один початковий комплект даних, службові скрипти, документація, тести й засоби збирання. Не входять config.json із секретами, data/current, backup, медіазавантаження, .git, .venv, кеші, журнали, тимчасові файли чи приватні ключі. PACKAGE_SHA256.json перевіряє кожен файл архіву.

Початкові 8 файлів data/default збережено без зміни вмісту. Старі звіти швидкодії Raspberry Pi не видаються за вимірювання Orange Pi. Старі інсталятори RPI5, жорстко задана адреса плати та параметри завантаження Raspberry Pi прибрані.

Основні документи: README.md, INSTALL_ORANGEPI.md, ADMIN.md, AFTER_SCHOOL_SLIDESHOW.md, SECURITY.md і RELIABILITY.md. Новий код kiosk встановлюється root-owned поза /opt/lyceumtv, щоб вебсервер не міг його змінювати.
