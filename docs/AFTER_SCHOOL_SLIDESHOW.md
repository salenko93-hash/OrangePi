# Фото, відео та музика після уроків

У навчальний день після останнього уроку до 17:00 TV показує заголовок і медіафайли. Оголошення, назви файлів, лічильники та післяурочний бігучий рядок не виводяться.

## Додавання файлів

1. Відкрийте `/ops`, увійдіть із Dispatcher або Admin key.
2. Вкладка **MEDIA / SIGNAGE** → **СЛАЙД-ШОУ ПІСЛЯ УРОКІВ**.
3. Оберіть кілька фото та/або відео й натисніть **ДОДАТИ ФОТО / ВІДЕО**.
4. Для музики оберіть окремий аудіофайл і натисніть **ДОДАТИ МУЗИКУ**.
5. Задайте гучність і ID екрана зі звуком, натисніть **ЗБЕРЕГТИ ЗВУК**. Типовий екран — `main-hall`, який використовує kiosk.

Формати й максимальні розміри:

| Вміст | Формати | На один файл |
|---|---|---|
| Фото | JPG, PNG, WEBP | 15 МБ |
| Відео | MP4, WEBM | 200 МБ |
| Музика | MP3, WAV, OGG, M4A | 35 МБ |

Для Orange Pi рекомендовано MP4 з H.264/AAC і роздільністю до 1280×720. Підтримка інших кодеків залежить від установленого Chromium. Завантаження не перетворює кодеки.

## Послідовність та звук

- Спочатку йдуть усі фото, кожне по 3 секунди, у порядку додавання.
- Тривалість одного фото-блоку — кількість фото × 3 секунди. Для 20 фото це 60 секунд.
- Один обраний трек супроводжує весь фото-блок. Якщо він коротший — повторюється; довший — зупиняється наприкінці фото-блоку.
- Потім відтворюються всі вибрані відео до кінця, у порядку додавання. Музика фото-блоку зупинена; відео має власний звук.
- Після останнього відео починається нове коло фото, а музика запускається спочатку. Без відео повторюється тільки фото-блок.
- Без фото музика не запускається. Кнопка **БЕЗ МУЗИКИ** вимикає лише супровід фото; гучність 0 вимикає також звук відео.
- На інших зареєстрованих екранах показ іде без звуку. Звичайний Music Scheduler не накладається на активний медіапоказ.
- Непрацюючий файл пропускається після помилки або 10 секунд без завантаження/прогресу. Повторна спроба для повністю недоступної колекції — під час наступного оновлення.

Зміни медіатеки та музики потрапляють на TV протягом 30 секунд. Під час тривоги, хвилини мовчання або завершення післяурочного режиму відео й музика зупиняються. Системні аудіоподії мають пріоритет над музикою та звуком відео.

Кнопка **ПРИБРАТИ З ПОКАЗУ** прибирає вибраний файл зі слайд-шоу, залишаючи його в медіатеці. Старі записи медіатеки не потрапляють до показу автоматично. Дати/час доступності медіазаписів враховуються.

## Перевірка у вихідні або ввечері

Натисніть **ПЕРЕГЛЯНУТИ ЗАРАЗ** або відкрийте `/slideshow-preview`.
Кнопка **З МЕДІАТЕКИ** використовує фото, відео й музику сервера. Натисніть **УВІМКНУТИ ЗВУК**, щоб браузер дозволив аудіо.
Можна окремо обрати фото/відео та музику з комп’ютера — вони відтворюються локально і не завантажуються на Pi.

Для повністю локального перегляду відкрийте `public/slideshow-preview.html` у браузері або `/slideshow-preview?local=1` на сервері. Цей режим не звертається до API. Закриття або вихід зі сторінки зупиняє звук. Передперегляд не змінює робочий TV і не відтворює його тривогу.

## Відновлення та очищення 3.5.1

Тимчасова помилка музики запускає повторні спроби завантаження. При втраті зв’язку з робочим API live-медіа зупиняються до отримання свіжого стану; локальний передперегляд працює незалежно. Прострочений післяурочний стан не запускає показ після 17:00.

Видалення запису з MEDIA LIBRARY прибирає файл лише за відсутності інших посилань на нього. Для залишків попередніх завантажень використовуйте «ОЧИСТИТИ НЕВИКОРИСТАНІ ФАЙЛИ»: застосунок покаже кількість і обсяг перед видаленням. Файли, завантажені протягом останньої години, зберігаються.
