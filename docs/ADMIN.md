# Адміністрування

Відкрийте `https://IP_ORANGE_PI/admin`. У 3.7.1 немає спільних стандартних ключів: вони генеруються на пристрої. Отримання через SSH:

```powershell
$boardIP = Read-Host "Orange Pi IP"
ssh -t "admin@$boardIP" "sudo /usr/local/sbin/lyceumtv-show-keys"
```

Власні ключі зберігаються при повторному встановленні. Старі відомі стандартні ключі, навіть із відновленого backup, замінюються випадковими. Нові ключі в панелі мають містити не менше 24 символів і відрізнятися між ролями. Якщо доступ зник після відновлення старої копії, отримайте актуальні ключі через SSH.

Admin керує розкладом, джерелами синхронізації, тривогою, погодою, хвилиною мовчання, екранами й заголовком слайд-шоу. Operations (`/ops`) доступний Admin/Dispatcher. Teacher має лише дозволені вчительські API. Публічний розклад і відображення TV залишаються відкритими для читання.

Панелі не зберігають ключі у localStorage. HttpOnly-сесія діє дві години, скидається після перезапуску сервера, відкликається кнопкою **ВИЙТИ** і стає недійсною після зміни ключа своєї ролі. Одна браузерна сесія означає одну роль у всіх вкладках. Для розділення ролей використовуйте різні профілі браузера.

Додатковий TV спочатку збережіть у **ЕКРАНИ**, потім натисніть **ПІДКЛЮЧИТИ**. Приватне посилання відкрийте на відповідному пристрої після налаштування довіри до TLS. Повторне створення токена припиняє доступ попереднього пристрою. Головний kiosk Pi підключається автоматично.

Передперегляд слайд-шоу та DEMO — окремі режими, які не надсилають команд на робочий TV. Ліміти медіатеки й подальші перевірки наведені в [README](../README.md) та [SECURITY.md](SECURITY.md).
