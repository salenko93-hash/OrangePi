# Академічний дизайн 3.5.1

TV, автономний DEMO й передперегляд використовують спільну тему `public/css/academic.css`, яка завантажується після базового tv.css.

- Темно-синій фон #09192f / #102b4e, світлі картки, темний основний текст #172d49.
- Єдині кольори класів, золотий акцент лише для чергового класу, окремий бейдж заміни.
- Кабінет виділений фоном, більшою вагою та розміром; предмет отримав більше горизонтального простору.
- Прибрані декоративні орбіти, книжечки та численні кольорові градієнти.
- Червоний режим тривоги, повідомлення та покрокова інструкція збережені.
- У слайд-шоу один рядок заголовка та великий кадр без обрізання. Фото змінюються раз на 3 секунди, відео відтворюється до кінця; лише плавне згасання, без zoom. Reduced motion вимикає згасання.
- У передперегляді для панелі керування зарезервовано окреме місце над макетом.

Дані розкладу та правила календаря не змінювалися. Дизайн перевірено у Chromium на 1920×1080 і 1366×768, у тому числі для довгих назв предметів та викладачів. На фізичному TV перевірка відстані читання та кольорів ще потрібна.
